Quant Alert
A beginner Python project that monitors a watchlist of financial assets and generates technical alerts using moving averages.

What it does
The program:
- Takes a watchlist of financial assets.
- Retrieves one month of historical market data using yfinance.
- Extracts daily closing prices.
- Calculates a 5-day Simple Moving Average (SMA).
- Calculates a 20-day Simple Moving Average (SMA).
- Compares the most recent SMA values with the previous values.
- Detects bullish and bearish SMA crossovers.
- Prints a BUY, SELL, or HOLD signal.
- Sends the signal to Discord using a webhook.
- Keeps the Discord webhook URL in a .env file rather than exposing it in the source code.

## Architecture

```text
Watchlist
    │
    ▼
Get historical market data
    │
    ▼
Extract closing prices
    │
    ▼
Calculate 5-day SMA + 20-day SMA
    │
    ▼
Remove invalid SMA values
    │
    ▼
Compare yesterday vs. today
    │
    ├──────────────────────┐
    │                      │
    ▼                      ▼
Bullish crossover    Bearish crossover
    │                      │
    ▼                      ▼
   BUY                    SELL
    │                      │
    └──────────┬───────────┘
               │
               ▼
        Discord notification

If no crossover occurs:
               │
               ▼
             HOLD
```
